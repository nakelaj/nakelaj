## 🔬 Lab Projects

### 🖥️ Active Directory Enterprise Simulation Lab
> Simulated a full enterprise Active Directory environment for a fictional company — NakelaTech Solutions — built entirely on Microsoft Azure with Windows Server 2025.

**What I built:**
- Deployed and configured Active Directory Domain Services (AD DS) and DNS
- Promoted a Windows Server VM to Domain Controller
- Designed a full Organizational Unit (OU) structure across 6 departments
- Provisioned user accounts and security groups with Role-Based Access Control
- Created and linked Group Policy Objects (GPOs) for security enforcement
- Deployed a member server (WS01) and joined it to the domain
- Validated policy delivery using `gpupdate /force` and `gpresult /r`
- Automated user and group provisioning with PowerShell scripts
- Documented real troubleshooting issues including domain join auth failures

**Tech used:** Azure | Windows Server 2025 | AD DS | DNS | GPMC | PowerShell
